Aufgabe:

Auf dieser Seite kann nach Kunden mit dem Namen gesucht werden. Die im Hintergrund verwendete SQL Query ist:

SELECT * FROM Kunden WHERE vorname = "{vorname}" OR nachname = "{nachname}"

Für {vorname} und {nachname} werden in diesem Fall unsicher! die Werte aus den Feldern unten eingesetzt.

SQL-Injection Bei einer SQL-Injection ist das Ziel mit den Eingabemöglichkeiten (wie z.B: hier Vorname und Nachname) die SQL Query so zu verändern, dass zum Beispiel mehr Informationen ausgegeben werden als vorgesehen. Damit kann man oftmals auf die komplette Datenbank zugreifen.
Beispiel:
Es wird neben dem Namen noch ein "OR 1=1" hinzugefügt. Die Bedingung 1=1 ist immer wahr, in Verbindung mit OR müssten dann alle Einträge der Datenbank angezeigt werden. Aber Achtung! Es funktioniert nur, wenn die Anführungszeichen so eingegeben werden, dass kein Fehler entsteht und das OR 1=1 nicht in den Anführungszeichen steht.

Ziel:

Das Ziel ist es hier alle Kundendaten auszulesen.
