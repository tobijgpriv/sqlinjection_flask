SQL Injection

Diese Webanwendung ist erstellt worden um einfache SQL Injection Angriffe zu erlernen und durchzuführen. Dafür wurden verschiedene Level erstellt, die einerseits eine Suche in einer Kundendatenbank und andererseits einen Login simulieren. Die Anwendung ist sehr einfach gehalten und beinhaltet nur die grundlegenden Angriffe um das Verständnis für SQL-Injection Angriffe zu schulen. Um tiefer in die verschiedenen Angriffsmöglichkeiten mittels SQL-Injection einzusteigen wird auf die kostenlose Web Security Academy von Portswigger verwiesen. Die folgenden Seiten stehen zur Verfügung:
  1. Suche in einer Kundendatenbank (verwundbar)
  2. Suche in einer Kundendatenbank (sicher)
  3. Suche in einer Kundendatenbank, Angriffe mit JOIN (verwundbar)
  4. Login (verwundbar)
  5. Zusatzaufgabe: SQLMap
