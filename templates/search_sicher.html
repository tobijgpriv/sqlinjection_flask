Sicheres Programmieren

Vergleiche den unsicheren und den sicheren Code miteinander:

Quellcode (unsicher) 
conn = get_db_connection()
if conn is None:
    fehlermeldung = "Fehler bei der Verbindung zur Datenbank."
else:
    try:
        cursor = conn.cursor()
        query = f"""
            SELECT *
            FROM Kunden
            WHERE vorname = "{vorname}" OR nachname = "{nachname}"
        """
        cursor.execute(query)
        daten = cursor.fetchall()
    except Error as e:
        fehlermeldung = f"Fehler bei der Abfrage: {e}"
    finally:
        cursor.close()
        conn.close()
Quellcode (sicher) 
conn = get_db_connection()
if conn is None:
    fehlermeldung = "Fehler bei der Verbindung zur Datenbank."
else:
    try:
        cursor = conn.cursor()
        query = """
            SELECT *
            FROM Kunden
            WHERE vorname = %s OR nachname = %s
        """
        cursor.execute(query, (vorname, nachname))
        daten = cursor.fetchall()
        print(daten)
    except Error as e:
        fehlermeldung = f"Fehler bei der Abfrage: {e}"
    finally:
        cursor.close()
        conn.close()
Die Lösung: Prepared Statements

SQL-Abfragen lassen sich mit Prepared Statements absichern. Dabei wird die Abfrage nicht mehr als einfacher Text zusammengebaut und so an die Datenbank geschickt. Genau das ist im unsicheren Code das Problem: Wird die Abfrage einfach als String zusammengesetzt, kann eine Angreiferin oder ein Angreifer über die Eingabe auch auf Teile der Abfrage einwirken, auf die sie oder er eigentlich keinen Zugriff haben sollte.

Bei Prepared Statements wird die Struktur der Abfrage zuerst festgelegt, und erst danach werden die Nutzereingaben eingesetzt. Die Datenbank weiß so jederzeit genau, was fester SQL-Code ist und was reine Nutzereingabe ist — eine Nutzereingabe kann die Struktur der Abfrage dadurch nicht mehr verändern. Das Beispiel oben ist in Python geschrieben, aber nahezu jede Programmiersprache bietet eine ähnliche Möglichkeit für den sicheren Zugriff auf Datenbanken.
