        conn = get_db_connection()
        if conn is None:
            fehlermeldung = "Fehler bei der Verbindung zur Datenbank."
        else:
            try:
                cursor = conn.cursor()
                query = """
                    SELECT *
                    FROM Kunden
                    WHERE vorname = %s OR nachname = %s
                """
                cursor.execute(query, (vorname,nachname))
                daten = cursor.fetchall()
                print(daten)
            except Error as e:
                fehlermeldung = f"Fehler bei der Abfrage: {e}"
            finally:
                cursor.close()
                conn.close()
Die Lösung Prepared Statements SQL Abfragen können über prepared Statements abgesichert werden. Dabei wird die SQL Abfrage nicht einfach zu einem String zusammengefügt und an die Datenbank gesendet. Wird die SQL Query einfach zusammengefügt, kann ein Angreifer immer auch auf Teile der SQL Abfrage zugreifen auf die er keinen Zugriff haben sollte.

Bei prepared Statements wird die SQL Abfrage zuerst vorbereitet und danach die Nutzereingabe eingefügt, daher kann das Programm zwischen eigentlichem SQL Code und vom Nutzer eingefügtem SQL Code unterschieden werden (siehe sicherer Code). Das Beispiel oben ist in Python geschrieben. Die anderen Sprachen haben aber alle ähnliche Funktionen um den sicheren Zugriff auf die Datenbank zu erlauben!
