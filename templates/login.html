Aufgabe:

Auf dieser Seite kann man sich zu einem Kundenportal anmelden. Man gibt Vorname und Passwort ein und falls die Eingaben richtig sind, ist der Login erfolgreich. Die im Hintergrund verwendete SQL Query ist:

SELECT vorname,passwort FROM Kunden JOIN Kunden_Passwoerter ON Kunden.ID = Kunden_Passwoerter.KundenID WHERE vorname = "{vorname}" AND passwort = "{passwort}

Für {vorname} und {passwort} werden in diesem Fall unsicher! die Werte aus den Feldern unten eingesetzt. Werden 1 oder mehr Datensätze zurückgegeben, so wird der Login als erfolgreich angesehen.

Ziel:

Das Ziel ist es sich als Benutzer mit dem Vornamen Admin einzuloggen, ohne das Passwort zu verwenden.

Hilfen:

Hilfe 1:

Das Ziel ist es also die SQL Query so anzupassen, dass auf jeden Fall ein oder mehrere Ergebnisse zurückgeliefert werden, obwohl das Passwort nicht stimt.

Hilfe 2:

Das kann zum Beispiel mit einem OR 1=1 mit passenden Anführungszeichen erreicht werden.

Hilfe 2 Alternative:

Zwei Bindestriche -- sind das Kommentarzeichen in SQL, das heißt ab dem Kommentarzeichen wird das SQL Statement nicht mehr beachtet. Vor und nach dem Kommentarzeichen muss ein Leerzeichen sein!
Kannst du so die Passwortabfrage abschalten?

Hilfe 3 Alternative:

Das Kommentarzeichen muss außerhalb der Anführungszeichen stehen und auch danach müssen die Anführungszeichen passen.
